# CLAUDE.md

## Overview

`basicami` is an asyncio-based Asterisk Manager Interface (AMI) client for Python, published to PyPI as `basicami`. Companion to `basicagi`. Send arbitrary AMI actions, originate calls, and collect events. Andrius's own (`andrius/asterisk-basicami`). Actively maintained - last commit 2026-03-07.

## Stack

Python (`pyproject.toml`, `basicami/`), ruff, pytest (`tests/`).

## Commands

- `pip install basicami`; run tests with pytest. Confirm exact commands against `pyproject.toml`.
